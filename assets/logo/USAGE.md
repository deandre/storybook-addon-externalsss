# Externalsss Logo

The Spill symbol is shared by Externalsss and its release-automation GitHub App. Its loose body suggests motion; the detached cobalt drop is the deliberately external element.

## Colors

| Role | Hex | RGB |
| --- | --- | --- |
| Vermilion body | `#C83F26` | `200 63 38` |
| Cobalt drop | `#3158C8` | `49 88 200` |
| Ink wordmark | `#193A36` | `25 58 54` |
| GitHub App badge background | `#FFE057` | `255 224 87` |
| Dark-mode vermilion | `#F56D50` | `245 109 80` |
| Dark-mode cobalt | `#90A7FF` | `144 167 255` |

Use the full-color artwork on white or other light backgrounds. Use `externalsss-symbol-dark.svg` on dark UI backgrounds, the one-color ink files where color is unavailable, and the reversed white files for dark monochrome use. Do not put the default full-color mark on a dark background without checking contrast. Do not stretch, rotate, outline, or add effects to the artwork.

Keep clear space around the artwork at least as wide as the detached drop. The symbol is designed for use at 16 px and larger; use the horizontal lockup at 160 px wide or larger. For smaller spaces, use the symbol alone.

## Files

- `externalsss-symbol.svg`: full-color symbol.
- `externalsss-symbol-dark.svg`: adjusted full-color symbol for dark UI.
- `externalsss-lockup.svg`: horizontal symbol and outlined wordmark.
- `externalsss-wordmark.svg`: outlined wordmark in ink.
- `*-mono.svg` and `*-reversed.svg`: one-color and white variants.
- `externalsss-github-app.png`: transparent, centered 200 x 200 App badge artwork. Set the App badge background color to `#FFE057` in GitHub.

The wordmark is outlined from [Bricolage Grotesque](https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque), licensed under the [SIL Open Font License 1.1](https://github.com/google/fonts/blob/main/ofl/bricolagegrotesque/OFL.txt). The SVGs do not require the font to be installed.
